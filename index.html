What is an operating system?

An operating system (OS) is the main software that connects users and apps to computer hardware. It helps the computer run programs, organize files, control memory, and protect information.

Processes

The OS schedules programs and shares CPU time.

Memory

It gives running apps memory and keeps their data separated.

Files

It organizes folders, files, and storage access.

Security

Accounts, permissions, updates, and protections help keep devices safe.

Architecture: Applications interact with system services and the kernel, which manages hardware such as the CPU, RAM, and storage.

Explore the three systems

Popular for gaming

🪟 Windows

Microsoft's OS is widely used in schools, offices, and gaming PCs.

Advantages

Large app library, broad hardware support, excellent game compatibility.

Limitations

Licensing can cost money; security updates and maintenance matter.

Files & security

File Explorer, NTFS, Microsoft Defender, user accounts, and permissions.

Apple ecosystem

🍎 macOS

Apple's desktop OS is designed for Mac computers.

Advantages

Polished interface, close hardware integration, strong creative tools.

Limitations

Mac hardware can be expensive; fewer native games.

Files & security

Finder, APFS, Gatekeeper, FileVault, and app permissions.

Open source

🐧 Linux

Linux powers desktops, servers, and many developer tools. Ubuntu and Fedora are examples of distributions.

Advantages

Highly customizable, many free distributions, powerful development tools.

Limitations

Some commercial apps and games need alternatives or extra setup.

Files & security

Common file systems include ext4; permissions use users, groups, and read/write/execute access.
