Real-world example

What happens when you visit a website?

  1. Application: The browser uses DNS to find the website's IP address and HTTPS to request content.
  2. Transport: TCP (or QUIC over UDP) helps deliver data between the browser and server.
  3. Internet: IP addresses identify the source and destination; routers forward packets toward the server.
  4. Network Access: Ethernet or Wi-Fi carries frames across the local connection.

At the destination, the process is read in reverse as each layer passes the data upward.

PowerCert Animated Videos — a visual overview of networking layers and how data moves through them.

What I Learned
  • The TCP/IP model organizes network communication into four layers.
